# 🚆 Railway Reservation System

A simple Python-based Railway Reservation System that allows users to view available trains, check seat availability, and book railway tickets. The project demonstrates the use of Python dictionaries, loops, conditional statements, and user input handling.

---

## 📖 Introduction

The Railway Reservation System is a Python project designed to simplify train ticket booking. It enables passengers to:

- View available trains
- Check seat availability
- Book train tickets
- Automatically update available seats after booking

This project is suitable for beginners learning Python programming concepts.

---

## 🎯 Problem Statement

Traditional manual railway ticket booking is:

- Time-consuming
- Difficult to manage passenger records
- Difficult to maintain seat availability accurately

This project provides a simple computerized solution for railway reservations.

## ⚙️ Procedure

1. Store train details using Python dictionaries.
2. Display menu options.
3. Accept the user's choice.
4. Verify train number.
5. Check seat availability.
6. Book the ticket if seats are available.
7. Reduce the available seat count.
8. Display booking confirmation or error message.

---

## ▶️ How to Run

1. Install Python 3.
2. Download the project files.
3. Open a terminal or command prompt.
4. Navigate to the project folder.
5. Run the program:

```bash
python railway_reservation.py
```
